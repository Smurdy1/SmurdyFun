Practice US States by typing the highlighted states.

What this US States quiz covers

This practice set covers the 50 states, the first-level political subdivisions of the United States. It focuses on internal locations, state names, regional patterns, and the shapes created by state borders.

How the subdivision typing quiz works

One state is highlighted. Type its name to answer and continue through all 50 states.

Gameplay tip: Connect each subdivision name with its position inside the parent country before typing.

What you'll practice

You have to recall and spell the full subdivision name here, so recognizing the right area by itself isn't enough.

A good way to start

Use the highlighted shape to find the right part of US States, think of nearby subdivisions, and then type the full name.

When this mode helps

Try this after the click subdivision quiz feels familiar, especially if the names still come slowly.

One mistake to watch for

Don't jump from a partial name to an answer. Check the shape's position and neighbors first.

What makes this group challenging

The central and northeastern states are usually harder than the large western states because many are similar in size or packed closely together.

Study tip

Break the map into the Northeast, South, Midwest, and West, then practice the full country after each section feels familiar.

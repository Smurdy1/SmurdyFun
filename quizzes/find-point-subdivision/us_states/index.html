Find the Subdivision from a Point / US States / 50 states

Identify which state in this set contains each point.

How well do you know state boundaries?

This practice set covers the 50 states, the first-level political subdivisions of the United States. It focuses on internal locations, state names, regional patterns, and the shapes created by state borders.

A point near New York City, Kansas City, or the Four Corners can punish a rough mental map very quickly.

The rectangle trap

Several western and central states look simple enough that it is tempting to remember them as interchangeable boxes. Their neighbors and relative position are usually the better clue.

How the subdivision point quiz works

A point appears inside one subdivision. Type the state that contains it.

Try this once you know the main subdivision outlines and want a more exact boundary test.

Tip: Judge which subdivision contains the point, especially when it lies near an internal boundary.

What you'll practice

This tests whether you know which subdivision actually contains a point, including spots far from a familiar city or label.

One mistake to watch for

Don't choose a subdivision just because it has the nearest well-known city. Pick the one that contains the point.

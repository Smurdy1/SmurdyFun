Type the US State Capitals Quiz

Type the Capitals / US States / 50 states

Learn all 50 US state capitals with the same state map used by Smurdy's other US geography quizzes.

What the US state capitals quiz covers

This quiz includes all 50 states and their current capital cities. Each question keeps the state visible on the map so you learn the capital together with its geographic location.

Albany, Sacramento, Carson City, Juneau, and Austin are all in the same 50-answer set.

Why Washington, DC is not included

Washington, DC is the capital of the United States, not a state capital. This quiz covers exactly the 50 states, so the answer set contains 50 state capitals.

How the capitals quiz works

One state is highlighted and named on the map. Type its capital city, submit your answer, and Smurdy briefly marks the capital's location before moving on through all 50 states.

Use this when you know the states in this set and want to add capital-city recall without losing the geographic context of the map.

Tip: Use the highlighted state as context, but try to recall the capital before looking for where the answer dot appears.

What makes state capitals challenging

Many state capitals are not the state's largest or best-known city. Pairs such as New York and Albany, California and Sacramento, and Nevada and Carson City reward direct recall instead of guessing the most famous city.

How to learn the 50 state capitals

Learn capitals by region first, then mix the full set. The Northeast and Midwest are useful clusters because several states and capitals are packed closely together.

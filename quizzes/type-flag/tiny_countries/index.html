Small countries, unrelated flag families

This flag quiz uses the same countries as the matching map quizzes, keeping flag and map practice aligned.

Monaco, San Marino, Liechtenstein, Nauru, and Tuvalu have almost nothing geographic in common besides being small.

How the flag quiz works

One flag appears at a time. Type the country it represents, or choose Give Up to reveal the answer. The round continues through all 28 countries.

Tip: Check the stripe direction, color order, symbols, and proportions before answering.

Do not overlearn by continent

This set is deliberately scattered, so regional shortcuts help less than they do in a normal continent quiz.

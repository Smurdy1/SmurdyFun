The same 20-country language set

This set uses the same 20-country Spanish-speaking group as Smurdy's map and capitals quizzes, covering 18 countries in the Americas plus Spain and Equatorial Guinea.

Spain, Mexico, Argentina, Guatemala, and Equatorial Guinea make the range of designs pretty wide.

How the flag quiz works

One flag appears at a time. Type the country it represents, or choose Give Up to reveal the answer. The round continues through all 20 countries.

Tip: Check the stripe direction, color order, symbols, and proportions before answering.

One way to learn this set

Study the Central American flags together, then South America, the Caribbean, and finally Spain and Equatorial Guinea before mixing the full set.

Africa Flag Quiz

Type the Flags / Africa / 56 flags

Type the place represented by each of the 56 African flags.

What this Africa quiz covers

This set covers North, West, Central, East, and Southern Africa along with the continent's island countries and the other places in Smurdy's Africa map group.

How the flag quiz works

One flag appears at a time. Type the country or territory it represents, or choose Give Up to reveal the answer. The round continues through all 56 countries and territories.

Gameplay tip: Check the stripe direction, color order, symbols, and proportions before answering.

What you'll practice

This mode builds visual recognition and name recall together. You have to produce the full place name instead of choosing it from a list.

A good way to start

Identify the broad design family first, then use the smallest distinctive feature to separate it from similar flags.

What makes this set challenging

Red, yellow, and green appear across many African flags, making stripe order and central symbols especially useful clues.

Study tip

Study neighboring countries together and note which Pan-African designs add a star, crest, or different stripe direction.

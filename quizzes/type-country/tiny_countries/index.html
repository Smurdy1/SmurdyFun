Type the Countries: Tiny Countries Map Quiz

Type the Countries / Tiny Countries / 28 countries

Practice the names and locations of tiny countries by typing the highlighted countries.

Tiny Countries gathers small sovereign states from Europe, the Caribbean, the Indian Ocean, and the Pacific. These are the places most likely to disappear into a normal world map at first glance.

Monaco, San Marino, Liechtenstein, Tuvalu, and Nauru are small enough that location context matters as much as outline shape.

Typing tiny places is its own problem

A country can be visually obvious once you notice it and still be hard to name quickly. This set is good at separating those two skills.

How the typing map quiz works

One country is highlighted on the map. Type its name to answer, using the map shape and location as your clue. The round continues through all 28 countries, making this useful for spelling practice as well as map recognition.

Try this once the country shapes in this set look familiar but some names still take a second to remember.

Tip: Say each answer in your head before typing it. That small pause helps connect the written name to the map.

What you'll practice

Knowing roughly where a place is won't be enough here. You have to pull the full name from memory and spell it, which helps when your map recognition is ahead of your name recall.

Memorize the neighborhood before the outline

Group the countries by region, especially European microstates, Caribbean islands, and Pacific island nations.

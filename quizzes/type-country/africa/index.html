Type the Countries: Africa Map Quiz

Type the Countries / Africa / 56 countries

Practice the names and locations of Africa by typing the highlighted countries.

A huge map with a dense middle

Africa contains more than fifty answers in this group, including North Africa, West Africa, the Horn, central Africa, southern Africa, and nearby island countries. It is one of the site's most detailed continent quizzes.

Ghana, Kenya, Botswana, and the two Congos make useful anchors, but a lot of the work happens between those anchors.

How the typing map quiz works

One country is highlighted on the map. Type its name to answer, using the map shape and location as your clue. The round continues through all 56 countries, making this useful for spelling practice as well as map recognition.

Try this once the country shapes in this set look familiar but some names still take a second to remember.

Tip: Say each answer in your head before typing it. That small pause helps connect the written name to the map.

The middle is harder than the outline

West Africa contains many smaller countries with short coastlines, while central and eastern Africa have several large inland neighbors that can blend together at first.

Learn a few anchor countries first

Learn the coastline first, then use those coastal countries to place the landlocked countries behind them.

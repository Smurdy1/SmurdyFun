What this Sub-Saharan Africa quiz covers

Sub-Saharan Africa contains the countries south of the Sahara according to Smurdy's stored group list. Removing North Africa still leaves a large map spanning West, Central, East, and Southern Africa.

How the typing map quiz works

One country is highlighted on the map. Type its name to answer, using the map shape and location as your clue. The round continues through all 49 countries, making this useful for spelling practice as well as map recognition.

Gameplay tip: Say each answer in your head before typing it. That small pause helps connect the written name to the map.

What you'll practice

Knowing roughly where a place is won't be enough here. You have to pull the full name from memory and spell it, which helps when your map recognition is ahead of your name recall.

A good way to start

First work out the subregion from the highlighted shape. Think of nearby places, say the answer in your head, and then type it.

When this mode helps

Try this once the shapes in Sub-Saharan Africa look familiar but some names still take a second to remember.

One mistake to watch for

Don't guess from the first letter or a vaguely similar outline. Check the highlighted area's position and neighbors first.

What makes this group challenging

The group is still large and includes many landlocked countries, so memorizing regional clusters is more effective than treating it as one uninterrupted list.

Study tip

Practice West, East, Central, and Southern Africa separately before using this combined quiz.

Type the Countries: Southern Europe Map Quiz

Type the Countries / Southern Europe / 18 countries

Practice the names and locations of Southern Europe by typing the highlighted countries.

What this Southern Europe quiz covers

Southern Europe centers on the Mediterranean-facing countries of the Iberian Peninsula, Italy, the Balkans, and nearby microstates included in the group. It gives concentrated practice for the lower half of the European map.

How the typing map quiz works

One country is highlighted on the map. Type its name to answer, using the map shape and location as your clue. The round continues through all 18 countries, making this useful for spelling practice as well as map recognition.

Try this once the country shapes in this set look familiar but some names still take a second to remember.

Tip: Say each answer in your head before typing it. That small pause helps connect the written name to the map.

Spanish-Speaking Countries No-Borders Map Quiz – Find the Countries

Find the Countries / Spanish-Speaking Countries / 20 countries

Test your map knowledge by finding each country in this set with borders hidden.

What this quiz covers

This set covers the 20 sovereign countries where Spanish is a national official or dominant language: 18 in the Americas, plus Spain in Europe and Equatorial Guinea in Africa. It focuses on countries rather than every territory or place where Spanish is widely spoken.

How the no-borders map quiz works

The quiz names a country, but the usual political borders are removed. Click where you think it belongs by using coastlines, neighboring landforms, distance, and your memory of the regional layout. This set covers all 20 countries.

Gameplay tip: Use coastlines and the positions of nearby large countries as anchors before judging smaller inland areas.

What you'll practice

With the border lines gone, you have to remember the layout itself. Coastlines, distances, and the order of nearby places become much more important.

A good way to start

Start from something you know: a coastline, peninsula, island, or large country. Place the target relative to it instead of guessing from empty space.

When this mode helps

Move to this mode when the bordered click quiz for this set starts to feel easy and you want a harder location test.

One mistake to watch for

The map may look blank, but it still has clues. Use coastlines, peninsulas, large rivers, and countries you already know.

What makes this set challenging

The group crosses three continents, and several nearby countries are intentionally excluded because Spanish is not their main national language. Central America and northern South America can also be easy to mix up when the full set is shuffled.

Study tip

Learn the set in clusters: Mexico and Central America, the Spanish-speaking Caribbean, South America, then Spain and Equatorial Guinea. After each cluster feels easy, mix all 20 together.

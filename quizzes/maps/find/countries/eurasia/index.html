Find the Countries: Eurasia No-Borders Quiz

Find the Countries / Eurasia / 94 countries

Test your knowledge of Eurasia by finding each country on a map with borders hidden.

From the Atlantic edge to the Pacific

Eurasia puts Europe and Asia on one continuous map. It is a huge set, from the Atlantic edge to the Pacific, with every kind of country size in between.

This set can put Portugal and Japan in the same run, with dozens of countries and several very different map scales between them.

How the no-borders map quiz works

A country name appears on a map with the political borders hidden. Click where it belongs. The coastline stays, so you still have some geography to work with.

Borderless mode is a good follow-up once the normal click map has become comfortable.

Tip: Pick out a coastline, peninsula or big country you know and judge the target from there.

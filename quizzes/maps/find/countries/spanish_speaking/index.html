Find the Countries: Spanish-Speaking Countries No-Borders Quiz

Find the Countries / Spanish-Speaking Countries / 20 countries

Test your knowledge of Spanish-speaking countries by finding each country on a map with borders hidden.

A language set that crosses an ocean

This set has the 20 sovereign countries where Spanish is an official or dominant national language. Most are in the Americas, with Spain and Equatorial Guinea far away from the rest.

Most of the set is in the Americas, then Spain and Equatorial Guinea pull you across the Atlantic.

How the no-borders map quiz works

A country name appears on a map with the political borders hidden. Click where it belongs. The coastline stays, so you still have some geography to work with.

Borderless mode is a good follow-up once the normal click map has become comfortable.

Tip: Pick out a coastline, peninsula or big country you know and judge the target from there.

The set is scattered across the world

The countries are spread across three continents. Nearby non-Spanish-speaking countries also make the set less obvious than a normal regional quiz.

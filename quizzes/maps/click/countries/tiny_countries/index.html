Click the Countries: Tiny Countries Map Quiz

Click the Countries / Tiny Countries / 28 countries

Learn the Tiny Countries map by clicking each country when its name appears.

The map's smallest targets

Tiny Countries collects small sovereign states from several parts of the world. Many of them are barely visible at normal world-map zoom.

Monaco can disappear beside France. Nauru has the opposite problem: there is hardly anything nearby to orient from.

You will need to zoom

This set is intentionally awkward at normal world-map scale. Get into the right neighborhood first; the exact target may be microscopic from far away.

How the click map quiz works

A country name appears above the map. Click it and keep going until the set is finished. The borders stay on the map, which makes this the easiest map mode to learn from.

For a map you barely know, this is usually the easiest place to start. It also works well as a refresher after leaving a region alone for a while.

Tip: If one answer keeps getting you, remember one neighbor or coastline beside it. That is usually enough to find it next time.

Precision matters more than recognition

Screen size is the main problem. Some answers are so small that knowing the neighborhood matters more than recognizing an outline.

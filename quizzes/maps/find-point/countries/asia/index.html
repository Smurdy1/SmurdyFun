Find the Country from a Point: Asia Quiz

Find the Country from a Point / Asia / 50 countries

Identify which country in this set contains each point placed on the map.

Long distances, sharp regional shifts

Asia is enormous, and the quiz can move from the Middle East to Central Asia or the Pacific coast in a few questions. Some regions have giant countries; others are packed tightly.

Japan and Uzbekistan barely feel like questions from the same map. Add Sri Lanka and the scale changes again.

How the point map quiz works

A point appears somewhere on the map. Type the country that actually contains it. The round keeps going through all 50 countries.

Point mode works best on a map you already know pretty well. It exposes fuzzy boundaries quickly.

Tip: Points near borders are the nasty ones. Check which side of the border the dot is really on.

Central and western Asia slow things down

Central Asia and mainland Southeast Asia are common trouble spots. The shapes are less forgiving when several neighbors sit close together.

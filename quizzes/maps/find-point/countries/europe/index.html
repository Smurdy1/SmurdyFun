Find the Country from a Point: Europe Quiz

Find the Country from a Point / Europe / 44 countries

Identify which country in this set contains each point placed on the map.

Europe puts a lot of countries into a small map. The big peninsulas are easy to orient around, but the middle of the continent gets crowded fast.

Portugal is hard to confuse. Luxembourg and Slovenia are a different story, and the microstates can disappear at normal zoom.

Near-border points

Europe makes this mode noticeably harder because a small movement can cross several national borders in a compact part of the map.

How the point map quiz works

A point appears somewhere on the map. Type the country that actually contains it. The round keeps going through all 44 countries.

Point mode works best on a map you already know pretty well. It exposes fuzzy boundaries quickly.

Tip: Points near borders are the nasty ones. Check which side of the border the dot is really on.

Common miss

A dot beside a famous country can still be across the border. Its exact side of the line decides the answer.

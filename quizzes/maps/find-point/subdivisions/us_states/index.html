Find the Subdivision from a Point: US States Quiz

Find the Subdivision from a Point / US States / 50 states

Identify which state in this set contains each point.

How well do you know state boundaries?

This set is the 50 US states. The western half gives you some big, obvious shapes; the Northeast and parts of the Midwest are much tighter.

A point near New York City, Kansas City, or the Four Corners can punish a rough mental map very quickly.

The rectangle trap

Several western and central states look like plain boxes at first glance. Their neighbors and position on the wider US map are usually better clues than the outline alone.

How the subdivision point quiz works

A point appears inside one subdivision. Type the state that contains it.

This is mainly for subdivision maps whose basic outlines are already familiar.

Tip: Near a boundary, slow down and check which side the point is on.

What the point exposes

This tests the parts of a subdivision far away from its best-known city or shape.

Common miss

A famous city nearby can pull you toward the wrong subdivision. The point itself decides the answer.

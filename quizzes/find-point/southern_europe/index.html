Find the Country from a Point: Southern Europe Quiz

Find the Country from a Point / Southern Europe / 18 countries

Identify which country in this set contains each point placed on the map.

Peninsulas, islands, and microstates

Southern Europe centers on the Mediterranean-facing countries of the Iberian Peninsula, Italy, the Balkans, and nearby microstates included in the group. It gives concentrated practice for the lower half of the European map.

Spain, Italy, and Greece are excellent anchors, but Malta, San Marino, Vatican City, and the Balkans make the small-scale details matter.

How the point map quiz works

A point appears somewhere inside one of the places in this group. Type the name of the country that contains it. The round covers all 18 countries and tests whether you understand the full area of each place rather than only recognizing its outline.

Try this when you know the main outlines and want a more exact test of where one place ends and another begins.

Tip: Check the point against coastlines and nearby countries before answering, especially when it sits close to a border.

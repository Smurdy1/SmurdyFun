Identify the Sub-Saharan Africa country that contains each point placed on the map.

What this Sub-Saharan Africa quiz covers

Sub-Saharan Africa contains the countries south of the Sahara according to Smurdy's stored group list. Removing North Africa still leaves a large map spanning West, Central, East, and Southern Africa.

How the point map quiz works

A point appears somewhere inside one of the places in this group. Type the name of the country that contains it. The round covers all 49 countries and tests whether you understand the full area of each place rather than only recognizing its outline.

Gameplay tip: Check the point against coastlines and nearby countries before answering, especially when it sits close to a border.

What you'll practice

This catches a different kind of mistake: knowing a place's general location but not how far its territory extends. Points near borders are especially good at exposing that gap.

A good way to start

Decide whether the point is near a coast, inland, or on an island. Then compare it with the nearest borders and recognizable shapes.

When this mode helps

Try this when you know the main outlines and want a more exact test of where one place ends and another begins.

One mistake to watch for

Don't pick the closest name you recognize. The answer is the place that actually contains the point.

What makes this group challenging

The group is still large and includes many landlocked countries, so memorizing regional clusters is more effective than treating it as one uninterrupted list.

Study tip

Practice West, East, Central, and Southern Africa separately before using this combined quiz.

Click the Countries: Sub-Saharan Africa Map Quiz

Click the Countries / Sub-Saharan Africa / 49 countries

Learn the Sub-Saharan Africa map by clicking each country when its name appears.

A very large set with few obvious shortcuts

Sub-Saharan Africa contains the countries south of the Sahara according to Smurdy's stored group list. Removing North Africa still leaves a large map spanning West, Central, East, and Southern Africa.

Senegal, Ethiopia, South Africa, Madagascar, and the Democratic Republic of the Congo are useful anchors, but they leave a lot of map between them.

How the click map quiz works

The quiz gives you one country at a time. Click the matching area on the map, then continue until you have completed all 49 countries. Borders remain visible, so this mode works well for first learning the shapes and positions.

Start here if the Sub-Saharan Africa map is new to you, if you haven't practiced it in a while, or if you want to get faster without hiding the borders yet.

Tip: Start with the largest or most familiar places, then use their borders to place nearby answers.

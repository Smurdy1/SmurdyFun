About Smurdy

Smurdy is a free geography quiz site I build and run myself. It started as a map quiz I wanted to play. Every time that got too easy, I added a harder version or some new kind of geography question.

I go by Smurdy online. I like geography and programming. I also spend a ridiculous amount of time staring at maps and thinking up geography challenges. A lot of features exist because I was playing the site, got annoyed by something, and changed it.

What is on the site

  • Bordered map quizzes where you click or type countries and US states.
  • No-borders quizzes that make you remember the map without political lines.
  • Point quizzes that test which place actually contains a location.
  • Flag quizzes for the world, regions, specialty groups, and US states.
  • Country capitals and all 50 US state capitals.
  • Weak Spots, which saves misses by quiz type so the same kind of question can come back later.

Why there are so many modes

Knowing a map has a few different failure modes. I can recognize France instantly and still blank on a flag or capital. That is why those show up as separate quizzes and separate Weak Spots.

Weak Spots

Weak Spots remembers both the place you missed and the kind of quiz you missed it in. A missed flag comes back as a flag. A missed no-borders question comes back without borders. If you get it right in Retry Missed, it leaves the list.

How places are counted

Country map quizzes generally follow Natural Earth's separately mapped features and group ordinary dependencies with their sovereign state. UN member and observer states are kept as separate answers, along with a small number of de facto entities that the source data already represents separately. Inclusion, naming, and displayed borders do not represent Smurdy's position on sovereignty or international recognition.

What I want to add next

The order changes constantly. Right now I want to add Locate modes, country-shape quizzes, more city stuff, Study Mode and a daily challenge. Subdivisions still have a lot of room to grow too.

Feedback actually changes the site

I catch plenty of bugs by playing Smurdy myself, but people also send useful corrections and weirdly specific ideas. If you notice something, send it here.

About Smurdy

Smurdy is a free, independent geography quiz project built for quick map practice, repeated learning, and several different ways of testing the same knowledge.

The goal is to make geography practice easy to begin and useful to repeat. You can choose a focused region, switch the kind of challenge, and immediately start learning without creating an account.

More than one kind of map quiz

Recognizing a country when its borders are visible is different from remembering its name or locating it without outlines. Smurdy separates those skills into distinct quiz modes:

Click the countries

See a place name and select the matching country or state on a political map.

Type the countries

Recall place names from the map instead of choosing from a list of answers.

Find without borders

Locate countries or states using coastlines, position, distance, and your mental map.

Find the point

Identify the country or state containing a marked point, with no political borders shown.

Practice by region

Each mode can be played with focused groups such as Europe, Southeast Asia, the Middle East, the Caribbean, or US states. Smaller regional quizzes make it possible to learn one area carefully before combining it with the rest of the world.

Built around improvement

Smurdy keeps quiz setup fast and gives direct feedback after each answer. Features such as Weak Spots use recent misses stored in your browser to create targeted review games, helping you return to places that still need practice instead of only replaying complete maps.

Who makes Smurdy?

Smurdy is created and maintained as an independent project by a developer who goes by Smurdy online. The site is shaped through ongoing development, personal interest in geography, and feedback from the people who use it.

Where the project is going

Smurdy currently focuses on interactive country and US state map quizzes. Planned additions include flag quizzes, capital quizzes, and Smurdy Daily, alongside continued improvements to existing modes, regional coverage, and review tools.

Smurdy is actively developed, so the exact order and design of future features may change as the project improves.

Help improve Smurdy

Bug reports, map or quiz corrections, and ideas for future modes are welcome.
